# /audio

Drop user-provided audio files here. Referenced by name from `kb-shortcuts.js`.

## rickroll.mp3

Played when the lightning bolt (glitch button) is clicked in the FX rack.

**Copyright note:** The original Rick Astley recording is owned by Sony/RCA.
You must own or license the file you place here. For a personal site this is
typically fine — for commercial use, license a cover or use a CC-licensed
substitute.

If this file is missing, the glitch button falls back to the synthesized
glitch sound (no error).
